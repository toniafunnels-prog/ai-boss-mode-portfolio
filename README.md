# AI Boss Mode Platform
### Built by Anthonia Dada | ToniaFunnels

## Overview
AI Boss Mode is a full SaaS platform that provides AI voice receptionists for home service businesses (HVAC, Plumbing, Electrical, Landscaping).

Lisa -- the AI receptionist -- answers all incoming calls 24/7, books appointments and captures leads automatically.

## What I Built

### Admin Panel
- Provider management dashboard
- Approve/Suspend/Reactivate providers
- Real time Supabase data
- GHL auto-deployment on approval
- Stripe customer creation
- Automated email notifications
- Audit log with event tracking
- Revenue calculation
- Search and filter

### Provider Dashboard
- Secure login per provider
- Edit business profile
- Lisa configuration panel
- Call log and recordings
- Appointments view
- Billing management
- Password change

### Backend API
- 15+ REST endpoints
- GHL sub-account auto-creation
- Email notifications (approval, welcome, suspension, reactivation)
- Stripe billing integration
- JWT authentication
- Audit logging

- **Stripe API** -- Creates customers and manages subscriptions
- **Supabase** -- Real time database with RLS security
- **SMTP Email** -- Automated transactional emails
